# Graphity Defied

A desktop browser cycling arcade. Turn the power, heart rate, or cadence in a Garmin FIT recording into hills and ride them with a simulated two-wheel bicycle. Try Endurance, Intervals, or Extreme without importing a workout.

| Input | Action |
| --- | --- |
| W / Up | Pedal |
| S / Down | Brake |
| A / Left | Lean back |
| D / Right | Lean forward |
| R | Respawn at the latest checkpoint |
| Esc | Pause or resume |

In **Track Lab**, choose the data series and compare the original recording with its generated terrain. **Playable** smooths the profile and stretches steep sections; **Raw** preserves abrupt changes and may be impassable. Purple marks indicate geometry changes. Orange bands identify steep sections, possible clearance problems, or missing data. Select a start position or a flagged section to practice it. Ride settings are saved locally and apply when a ride starts.

**Physics** is the default. Gravity, rolling resistance, wheel contact, rider input, and a fixed gear determine movement. **Data Driven** adds torque using one recorded series. **Constant Assist** adds steady torque for debugging. Neither assist mode sets speed directly. The HUD's game cadence comes from rear wheel rotation and gear ratio while the drivetrain is engaged; it is separate from the cadence in the file.

FIT files are decoded locally with the [Garmin FIT JavaScript SDK](https://github.com/garmin/fit-javascript-sdk). The app retains the original decoded and cleaned samples for the current workout. Short gaps can be interpolated; long gaps remain absent in the source and are marked where the geometry bridges them. Workout files are never uploaded or saved between sessions.

## Run locally

Use Node.js 22.12+.

```sh
npm install
npm run dev
npm run test
npm run build
npx playwright install chromium
npm run test:e2e
```

Run browser tests after the production build. To use an existing Chrome installation, set `GRAPHITY_BROWSER_CHANNEL=chrome`. See [DEPLOYMENT.md](DEPLOYMENT.md) for static hosting.

## Implementation

- `src/activity.ts` / `src/fit.ts`: independent FIT decoding, samples, gaps, and demos.
- `src/terrain.ts`: deterministic terrain, geometry checks, and lookup from track X to workout time.
- `src/settings.ts`: presets and local settings.
- `src/drivetrain.ts` / `src/movement.ts`: gear, cadence, torque, and assist policies.
- `src/bike.ts` / `src/rider.ts` / `src/game.ts`: Matter bodies and wheel joints, streamed terrain colliders, rider animation, and the Phaser scene.
- `src/main.tsx` / `src/charts.tsx`: React screens, Track Lab, and telemetry.
- `tests/`: Vitest and Playwright coverage, with synthetic FIT files generated by the SDK.

This is an arcade simulation for keyboard play. Track geometry checks do not guarantee completion. Crash detection uses rider contact and orientation; a ragdoll is outside this version. Very long activities are reduced for performance. Local storage only keeps tuning settings. Original procedural graphics; no game assets copied from Gravity Defied.
